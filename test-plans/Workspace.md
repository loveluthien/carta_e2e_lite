# Workspace test plan

**Source** [Workspace.spec.ts](../tests/Workspace.spec.ts) · **Cases** 8

| Scenario                       | Expected restore                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Mixed image and layout session | The cube returns on channel 4 with the saved gray colormap and 24 K at pixel (8, 8). The selected rectangle, its five-point spectral profile, floating widgets, and the moved File Header dialog return. The open Spectral Profiler settings panel restores its Smoothing tab, and the dialog restores its File Information tab. A rejected save can be retried, and opening a missing record preserves the live session.                                      |
| Generated moment and PV images | Save the open Moment Map and PV Generator panels with non-default settings. The moment selection and channels 1–3 return, and the regenerated mean reads 7 K at (8, 8). The PV source, line cut, averaging width 5, and channel bounds 10–30 return, and the regenerated PV has 21 spectral rows. The shared layout check reproduces the [floating window stacking bug](./WorkspaceBugs.md#floating-moment-map-settings-overtake-the-pv-generator-on-restore). |
| Plotted catalog                | The five-row local catalog returns with its table and teal source markers in the viewer.                                                                                                                                                                                                                                                                                                                                                                       |
| Online Data Query (SIMBAD)     | Restore the open SIMBAD Catalog tab with draft radius 0.05 and limit 7. Replay the original limit-2 query and restore both returned rows and their plotted markers.                                                                                                                                                                                                                                                                                            |
| Online Data Query (HiPS)       | Replay the original 16×16 HiPS cutout query for M 31 with SIN projection and 45° rotation. Restore the FITS pixels, the open HiPS Survey tab, and the unsent width of 24 in the form. The case reproduces the [HiPS form reset](./WorkspaceBugs.md#the-hips-survey-form-resets-on-workspace-restore).                                                                                                                                                          |
| Contours                       | Generate four contour levels with the min-max-scaling generator (Min 0.04, Max 0.10, N 4). Apply block smoothing factor 3 and leave factor 5 pending. Restore the generator and its parameters, keep Apply enabled for the pending change, and regenerate the white contour overlay.                                                                                                                                                                           |
| Vector Overlay                 | Save the open Styling tab with averaging width 4 and line thickness 2. Restore those values and regenerate the same vertex count and white vectors on the canvas.                                                                                                                                                                                                                                                                                              |
| Channel Map                    | The control, saved 1×2 grid, channel labels, and panels for channels 0 and 1 return. This case reproduces the [known Channel Map reset](./WorkspaceBugs.md).                                                                                                                                                                                                                                                                                                   |

Each scenario saves and opens through the File menu. The tests intercept workspace storage and use the real backend for FITS, catalog, and generated data. The shared check compares image order, active image, channel, polarization, raster RGB, docked tab groups, floating widgets, and visible dialogs. Playwright attaches before and after viewer and full-window PNGs.

The [Image Viewer plan](./ImageViewer.md) also covers independent PV-axis zoom and legacy workspace compatibility alongside its PNG export checks.

```sh
npm test -- --project=test-group2 tests/Workspace.spec.ts
```
