# Contours test plan

**Source:** [`tests/Contours.spec.ts`](../tests/Contours.spec.ts) · **Cases:** 4

Each case loads `HD163296_13CO_2-1_subimage.fits` on channel 24 in a fresh page. The tests drive contour controls through the UI, inspect read-only frame state for completed contour data, and compare reviewed PNGs of the histogram and unobstructed image viewer.

| Case                        | Actions                                                                                                                                                                                                      | Required checks                                                                                                                                                                                                  |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Generators                  | Generate levels using start-step-multiplier, min-max-scaling, percentages-ref.value, and mean-sigma-list. Apply the min-max levels.                                                                          | Level counts and ordering follow each mode; applied levels complete with vertices; channel histogram and rendered contour PNGs match baselines.                                                                  |
| Scaling                     | In min-max mode, generate levels with Linear, Log, Square root, Squared, Gamma, Power, Sinh and Asinh. Edit Alpha and Gamma, enter an invalid Alpha, reset parameters, and apply Linear and Asinh.           | All five levels match independent references for each mode; invalid Alpha is clamped and reset works; applied levels and vertices match, and the viewer changes with scaling.                                    |
| Apply, invalid input, Clear | Enter a nonnumeric level, then two valid levels; choose no smoothing and factor 3; Apply, Clear, and Apply again.                                                                                            | Invalid input leaves Apply disabled and no contours; valid levels and smoothing reach the frame; Clear removes vertices and the viewer overlay; recovery renders again. Compare applied and cleared viewer PNGs. |
| Styling                     | Start from positive and negative contours; increase thickness, choose white constant color, exercise Negative only, None, and Dashed line styles, then use tab10 mapped color, inversion, bias and contrast. | Each line style is selected in UI and frame state and matches its own viewer PNG; white RGB pixels occur in the contour canvas; vertices remain present; mapped viewer PNG matches its baseline.                 |

Run with `npx playwright test tests/Contours.spec.ts` in the configured Chromium project.
