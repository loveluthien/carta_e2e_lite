# Contours test plan

**Source:** [`tests/Contours.spec.ts`](../tests/Contours.spec.ts) · **Cases:** 8

The first four cases load `HD163296_13CO_2-1_subimage.fits` on channel 24. The matching and control cases use the lightweight `cube.fits` and shifted `matching-cube.fits` fixtures. Each runs in a fresh page, drives controls through the UI, inspects read-only frame state, and compares reviewed PNGs of the histogram or unobstructed image viewer.

| Case                        | Actions                                                                                                                                                                                                      | Required checks                                                                                                                                                                                                                                                                                         |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Generators                  | Generate levels using start-step-multiplier, min-max-scaling, percentages-ref.value, and mean-sigma-list. Apply the min-max levels.                                                                          | Level counts and ordering follow each mode; applied levels complete with vertices; channel histogram and rendered contour PNGs match baselines.                                                                                                                                                         |
| Scaling                     | In min-max mode, generate and apply levels with Linear, Log, Square root, Squared, Gamma, Power, Sinh and Asinh. Edit Alpha and Gamma, enter an invalid Alpha, and reset parameters.                         | All five levels match independent references for each mode; invalid Alpha is clamped and reset works; applied levels and vertices match, and the viewer changes with scaling.                                                                                                                           |
| Apply, invalid input, Clear | Enter a nonnumeric level, then two valid levels; choose no smoothing and factor 3; Apply, Clear, and Apply again.                                                                                            | Invalid input leaves Apply disabled and no contours; valid levels and smoothing reach the frame; Clear removes vertices and the viewer overlay; recovery renders again. Compare applied and cleared viewer PNGs.                                                                                        |
| Styling                     | Start from positive and negative contours; increase thickness, choose white constant color, exercise Negative only, None, and Dashed line styles, then use tab10 mapped color, inversion, bias and contrast. | Each line style is selected in UI and frame state and matches its own viewer PNG; white RGB pixels occur in the contour canvas; vertices remain present; mapped viewer PNG matches its baseline.                                                                                                        |
| Spatial matching            | Apply white contours to the shifted cube. Switch the dialog source with the frame lock on and off, match the cubes spatially, hide and show the contour layer, then unmatch and return to the source frame.  | Locked source selection changes the active image; unlocked selection does not. Matching projects the source contour onto the reference viewer with white RGB pixels and a reviewed PNG; hiding or unmatching removes it from the reference while preserving the source overlay.                         |
| Spectral matching           | Apply white contours to the shifted cube, enable only spectral matching, move the reference to channel 4, then unmatch and move the reference again.                                                         | The target follows to channel 2 and its contour pixels change; the reference never displays the target contour without spatial matching. The target viewer PNG has white RGB pixels, and unmatching preserves its channel and contour image.                                                            |
| Combined matching           | Apply white contours to the shifted cube, enable spatial and spectral matching together, move the reference to channel 4, then disable spectral and spatial matching in turn.                                | Both matching references stay enabled and the target follows to channel 2 while its contours project onto the reference viewer with white RGB pixels and a reviewed PNG. Disabling spectral matching preserves the spatial overlay; disabling spatial matching removes it while target contours remain. |
| Histogram and smoothing     | Cancel and confirm Per-cube histogram calculation, restore Per-channel, remove a level tag, then apply Block and Gaussian smoothing with factor 3.                                                           | Cancel leaves the channel histogram selected; the cube histogram completes and matches its PNG; removal changes the applied levels; both smoothing modes reach the frame and produce distinct reviewed viewer PNGs.                                                                                     |

Run with `npx playwright test tests/Contours.spec.ts` in the configured Chromium project.
